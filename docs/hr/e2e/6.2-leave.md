# 6.2 — الإجازات

**الهدف:** سياسة تمنح رصيداً، وموظف يطلب إجازة ويرى ما ستأخذه منه قبل الإرسال. بعد الاعتماد يُخصم الرصيد، وعند الإلغاء يعود. وتقويم الإجازات يعكس ذلك.

## المتطلبات
- 6.0 و6.1: مسار موافقة للإجازة.
- الحسابات **أ** و**ج** و**د**.

## 1. الإعدادات (إعدادات الموارد البشرية ← إعدادات الإجازات)
- [ ] نوع "سنوية" بالأيام ومدفوعة، ونوع "بلا راتب" بالأيام وغير مدفوعة.
- [ ] سياسة للسنوية:
  - منح شهري.
  - شريحة خدمة: بعد سنتين يزيد المنح.
  - ترحيل 5 أيام تنتهي بعد 3 أشهر.
  - حد السالب يومان.
  - لعقد "مفتوح" فقط.
- [ ] عطلة رسمية في الشهر القادم.
- [ ] حد أدنى للحضور في وحدة **د**: شخص واحد على الأقل.

## 2. الرصيد
- [ ] ملف **د** ← الإجازات: الرصيد والسجل يعكسان السياسة.
- [ ] تعديل الرصيد يدوياً بسبب (+2): يظهر في السجل مع السبب.

## 3. الطلب
- [ ] **د** ← إجازاتي ← طلب إجازة: يختار تواريخ تشمل العطلة الرسمية وعطلة نهاية الأسبوع.
  - [ ] المعاينة الحية تعدّ أيام العمل فقط، وتُظهر الرصيد الباقي.
- [ ] يرسل الطلب. يمر على المسار (6.1) حتى الاعتماد. يُخصم الرصيد ويظهر في السجل.
- [ ] طلب بنصف يوم: المعاينة نصف يوم.
- [ ] يسحب **د** طلباً معلّقاً: يُسحب طلب الموافقة.
- [ ] يلغي **د** إجازة معتمدة قبل بدئها: يعود الرصيد.

## 4. الموارد البشرية
- [ ] الدوام والإجازات ← طلبات الإجازة: التصفية بالحالة والنوع والموظف والتواريخ.
- [ ] تسجيل إجازة نيابة عن **د** من ملفه.
- [ ] إلغاء طلب معتمد بعد تأكيد.
- [ ] تقويم الإجازات: شبكة الشهر حسب الوحدة تُظهر من هو غائب.

## 5. المدير (ج)
- [ ] إجازاتي ← تبويب الفريق: شهر فريقه.

## (رفض)
- [ ] طلب يتجاوز الرصيد وحدّ السالب: يرفضه الخادم بسببه.
- [ ] طلب يكسر الحد الأدنى للحضور: يرفضه الخادم، أو يحذّر منه، حسب السياسة.
- [ ] إلغاء إجازة بدأت فعلاً: يرفضه الخادم، والطريق هو تعديل الرصيد.
- [ ] نوع "بلا راتب" معتمد: يجب أن يظهر لاحقاً كخصم في الرواتب (تحقق منه في 6.5).
