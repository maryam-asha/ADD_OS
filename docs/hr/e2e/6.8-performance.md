# 6.8 — الأداء

**الهدف:** دورة تقييم تُطلق وتمرّ بمراحلها بالترتيب:

> تحديد الأهداف ← التقييم الذاتي ← تقييم المدير ← المعايرة ← الإغلاق

في كل مرحلة لا يُفتح إلا ما يخصها. وعند الإغلاق يحصل كل موظف على تقديره النهائي ويراه.

## المتطلبات
- 6.0: وحدة فيها **د**، ومديره المباشر **ج**، وموظف ثالث في الوحدة نفسها.
- الحساب **أ**، وحساب **و** للقراءة فقط.

## 1. النموذج (إعدادات الموارد البشرية ← نماذج التقييم)
- [ ] أضف "التقييم السنوي":
  - سلّم من 1 إلى 5.
  - ثلاث كفاءات: "teamwork" بوزن 2، و"ownership"، و"service".
  - وزن الأهداف 40%.
- [ ] **(رفض)** كفاءتان بالرمز نفسه، أو كفاءة بلا اسم عربي: يُمنع الحفظ بسبب واضح.
- [ ] تعديل النموذج بعد إطلاق دورة عليه: الدورة تبقى على نسختها القديمة. تحقق من ذلك في خطوة 5.

## 2. الدورة (التوظيف والمواهب ← دورات التقييم ← دورة جديدة)
- [ ] الاسم والنموذج والفترة (السنة)، ونطاق "وحدة **د**"، ومواعيد المراحل الثلاث. تُفتح صفحة الدورة "مسودة"، وفيها زرا "تعديل" و"إطلاق".
- [ ] **(رفض)** نهاية الفترة قبل بدايتها.
- [ ] "إطلاق" بعد تأكيد:
  - [ ] المرحلة "تحديد الأهداف".
  - [ ] بطاقات الحالات: "مفتوح" بعدد موظفي الوحدة.
  - [ ] كل تقييم مقيّمه المدير المباشر.
  - [ ] زر "تعديل" اختفى.
- [ ] "إضافة موظف" من خارج الوحدة: يظهر تقييمه. **(رفض)** إضافته مرة ثانية.

## 3. الأهداف
- [ ] **د** ← شؤوني الوظيفية ← أهدافي وتقييماتي ← أهدافي:
  - [ ] هدف "رفع نسبة الإشغال" بوزن 60 في الدورة.
  - [ ] هدف ثانٍ بوزن 50: **(رفض)** "مجموع الأوزان 100 كحد أقصى، والمتبقي 40".
  - [ ] عدّله إلى 40 فيُحفظ.
- [ ] **ج** ← أهداف فريقي: يختار **د**، فيرى أهدافه ويضيف له هدفاً.
- [ ] **(رفض)** موظف يحاول تعديل أهداف زميل ليس من فريقه: يرفضه الخادم.
- [ ] الموارد البشرية ← الأهداف: التصفية بالموظف والدورة. إضافة هدف لموظف (الزر لا يعمل قبل اختيار موظف).
- [ ] ملف **د** ← الأداء: أهدافه عبر الدورات.

## 4. التقييم الذاتي
- [ ] **أ** ← "الانتقال إلى التقييم الذاتي" بعد تأكيد يذكر أن الأهداف ستثبت.
- [ ] **د** يعدّل هدفاً:
  - [ ] العنوان والوزن معطّلان، وتظهر ملاحظة.
  - [ ] التقدّم والحالة يتغيّران.
- [ ] **د** ← تقييماتي ← "تعبئة": الكفاءات الثلاث وأهدافه.
  - [ ] يقيّم بعضها فقط ويرسل بعد تأكيد. يقبله الخادم، لأن التقييم الذاتي يقبل تقييماً جزئياً.
- [ ] **(رفض)** **د** يحاول التعبئة ثانية: الزر لا يظهر. وإن أُرسل الطلب: "أُرسل هذا التقييم".

## 5. تقييم المدير
- [ ] **أ** ← "الانتقال إلى تقييم المدير".
- [ ] **ج** ← تقييمات أجريها ← "تقييم":
  - [ ] بجانب كل بند ما قدّره **د** لنفسه وتعليقه.
  - [ ] يُمنع الإرسال قبل تقدير كل البنود.
- [ ] **ج** يقدّر الكل، ويكتب تعليقاً وتوصية "ترقية"، ويرسل بعد تأكيد.
- [ ] صفحة الدورة ← التقييم:
  - [ ] درجات الكفاءات والأهداف والكلية من الخادم.
  - [ ] وزن "teamwork" مضاعف.
  - [ ] الأهداف 40%.
- [ ] "تغيير المقيّم" لتقييم لم يُقيَّم بعد: يُحفظ. **(رفض)** "تغيير المقيّم" لتقييم قيّمه **ج**: لا يظهر.

## 6. المعايرة والإغلاق
- [ ] **أ** ← "الانتقال إلى المعايرة". فتح تقييم **د** ← "معايرة" بدرجة 3.5 وسبب.
- [ ] **(رفض)** درجة 6 على سلّم من 5: يرفضها الخادم.
- [ ] **(رفض)** معايرة تقييم لم يقيّمه مديره.
- [ ] "إغلاق الدورة" بعد تأكيد صريح (لا تراجع):
  - [ ] كل التقييمات "نهائي".
  - [ ] تقدير **د** النهائي 4، وهو تقريب 3.5 المعايَرة.
  - [ ] التقييم الذي لم يقيّمه أحد بلا تقدير.
- [ ] **د** ← تقييماتي ← "قراءة النتيجة":
  - [ ] يرى تقييم مديره وتقديره النهائي.
  - [ ] **لا** يرى التوصية ولا المعايرة.

## (رفض) عامة
- [ ] بعد الإغلاق: لا زر انتقال، ولا تعديل لأي هدف في الدورة.

## الصلاحيات
- [ ] الحساب **و**: يرى الدورات والتقييمات والأهداف والنماذج، ولا يرى أي زر إطلاق أو انتقال أو معايرة أو إضافة.
- [ ] موظف بلا فريق: لا يرى تبويب "أهداف فريقي".
- [ ] **(رفض)** رابط تقييم موظف آخر في شؤوني الوظيفية: "هذا ليس تقييمك".

## سؤال مفتوح
- التوصية ("ترقية" أو "تعديل الأجر") اقتراح فقط ولا تُطبَّق تلقائياً. هل تريد من الموارد البشرية رابطاً مباشراً من التقييم إلى "تسجيل حدث" في ملف الموظف؟ لم يُبنَ هذا الرابط.
