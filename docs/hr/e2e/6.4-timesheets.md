# 6.4 — التايم شيت والكلفة

**الهدف:** موظف يوزّع ساعات أسبوعه على مراكز التكلفة، ويرسلها، فتُعتمد. وتقرير الوقت يوزّع الساعات المعتمدة حسب توزيع كلفة كل موظف، وينزل كملف CSV.

## المتطلبات
- 6.3: أيام حضور لـ **د** في أسبوع، للمقارنة.
- مسار موافقة لنوع "تايم شيت" (6.1).
- الحسابات **أ** و**ج** و**د**.

## 1. مراكز التكلفة (إعدادات الموارد البشرية ← مراكز التكلفة)
- [ ] أضف "GRANT-A" باسم "منحة أ"، و"OPS" باسم "العمليات".
- [ ] **(رفض)** رمز فيه مسافة أو رمز مكرر: رسالة واضحة.
- [ ] عطّل مركزاً: لم يعد يظهر للموظف عند تسجيل الساعات.

## 2. توزيع الكلفة (ملف **د** ← الكلفة والتايم شيت)
- [ ] "تغيير التوزيع": 60% GRANT-A و40% OPS من تاريخ اليوم.
  - [ ] لا يُحفظ قبل أن يكون المجموع 100%.
  - [ ] المركز الواحد لا يتكرر.
- [ ] تغيير ثانٍ من الشهر القادم: يظهر "مخطّط" والأول "الحالي".
- [ ] **(رفض)** تاريخ قبل آخر توزيع: محجوب في التقويم. وإن وصل الخادم، فرسالته تظهر.

## 3. التايم شيت (د ← شؤوني الوظيفية ← التايم شيت الخاص بي)
- [ ] الأسبوع يبدأ يوم الأحد، كأسبوع عمل ADD وكما يضبطه ADD Core (`config/hr.php`). اختيار أي يوم ينقلك إلى أحد أسبوعه.
- [ ] سطر GRANT-A وسطر OPS، مع ساعات بخطوات نصف ساعة، وملاحظة.
- [ ] مجاميع الأيام والأسطر صحيحة.
- [ ] منع الحفظ بسبب واضح عند:
  - [ ] 7.25 ساعة.
  - [ ] يوم يتجاوز 24 ساعة.
  - [ ] سطر فيه ساعات بلا مركز.
- [ ] حفظ ← إعادة تحميل الصفحة: الساعات والملاحظات باقية.
- [ ] الانتقال إلى أسبوع آخر وفيه تعديلات غير محفوظة: يسأل أولاً.
- [ ] "مقارنةً بالحضور" تُظهر الفرق يوماً بيوم.
- [ ] إرسال ← "بانتظار الاعتماد" ← الشبكة للقراءة فقط ← "استرجاع" يعيده مسودة.
- [ ] إرسال ثانٍ ← **ج** يرفضه ← يظهر "مرفوض" ← يعدّل **د** ويرسل (يحفظ أولاً ثم يرسل) ← يُعتمد.

## 4. الموارد البشرية (الدوام والإجازات ← التايم شيت)
- [ ] القائمة مصفّاة بالأسبوع والحالة والموظف. السطر يفتح لوحة فيها الأسطر والمقارنة.
- [ ] تبويب "لم يُسلَّم": من لم يرسل الأسبوع، مع التصفية بالوحدة.

## 5. التقرير (الدوام والإجازات ← الوقت حسب مركز التكلفة)
- [ ] مدى الشهر: الساعات المعتمدة فقط، موزّعة 60/40 حسب توزيع **د**.
- [ ] **(رفض)** مدى أكثر من سنة: تحذير، ولا يُرسل الطلب.
- [ ] "تنزيل CSV":
  - [ ] الملف باسم يذكر التاريخين.
  - [ ] العربية سليمة عند فتحه في Excel.
  - [ ] الأرقام تطابق الشاشة.

## (رفض)
- [ ] تسجيل ساعات في شهر مقفل في 6.3: يرفضه الخادم.
