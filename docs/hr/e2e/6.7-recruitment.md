# 6.7 — التوظيف

**الهدف:** طلب توظيف يُعتمد ويفتح شاغراً، ومتقدّم يمر على المراحل والمقابلات، ثم يُقدَّم له عرض يُعتمد ويقبله، فيُعيَّن موظفاً. ملفه يُفتح بأجر العرض ومهام التهيئة.

## المتطلبات
- 6.0: وحدة ومنصب ودرجة، ومدير توظيف (**ج**).
- 6.1: مساران لنوعي "طلب توظيف" و"عرض توظيف".
- 6.5: مكوّن "basic"، لأجر العرض.
- الحسابات **أ** و**ج** و**د**، وحساب بصلاحية `hr.recruitment.manage` بلا `hr.employees.create`.

## 1. المراحل (إعدادات الموارد البشرية ← مراحل التوظيف)
- [ ] أضف "فرز" بترتيب 20 و"مقابلة" بترتيب 30. المراحل الثابتة (عرض، تعيين، رفض، انسحاب) بلا زر تعديل.
- [ ] عطّل مرحلة: تختفي من خيارات النقل ومن أعمدة اللوحة.

## 2. طلب التوظيف
- [ ] التوظيف والمواهب ← طلبات التوظيف ← طلب جديد:
  - الوحدة والمنصب (المناصب تتبع الوحدة) والعدد 1.
  - السبب "بديل" يطلب اختيار الموظف المستبدَل.
  - مدير التوظيف **ج**.
  - الميزانية مع عملة.
- [ ] **(رفض)** حد أعلى للميزانية أقل من الأدنى: يُمنع الإرسال بسبب واضح.
- [ ] الطلب "بانتظار الاعتماد". يُعتمد عبر المسار، ويُظهر صندوق الموافقات ملخصه.
- [ ] **ج** ← الوظائف الداخلية والتوظيف ← طلبات التوظيف: يقدّم طلباً بنفسه (بلا اختيار مدير).

## 3. الشاغر
- [ ] لوحة الطلب ← إضافة شاغر: داخلي، بوصف، وتاريخ إغلاق، و"افتحه الآن".
- [ ] **(رفض)** إضافة شاغر لطلب غير معتمد: الزر لا يظهر.
- [ ] صفحة الشاغر: الإغلاق ثم الفتح، والتعديل.

## 4. المتقدمون
- [ ] إضافة طلب تقدّم:
  - [ ] شخص جديد بمصدر "ترشيح" (يطلب اختيار من رشّحه) وسيرة PDF.
  - [ ] متقدّم مسجّل مسبقاً، بالبحث عنه.
- [ ] **(رفض)** تقديم الشخص نفسه على الشاغر نفسه مرتين.
- [ ] **د** ← الوظائف الداخلية والتوظيف ← الوظائف المفتوحة: يتقدّم برسالة. تظهر "تقدّمت"، والطلب في "طلباتي".
- [ ] اللوحة: كل متقدّم في عمود مرحلته.

## 5. طلب التقدّم
- [ ] "فتح السيرة الذاتية": تُفتح في تبويب جديد.
  - [ ] الرابط ينتهي بعد دقائق. أعد فتحه لاحقاً فيعمل برابط جديد.
- [ ] النقل إلى "فرز" ثم "مقابلة": تظهر في "تنقّلات الطلب".
- [ ] جدولة مقابلة فيديو برابط ومقابِلَين (أحدهما **ج**). يُبلَّغان.
- [ ] **ج** ← مقابلات أجريها ← تعبئة البطاقة:
  - توصية، وتقديرات على معايير يسمّيها، وملاحظات.
  - تظهر في صفحة الطلب.
- [ ] **(رفض)** موظف ليس مقابِلاً يحاول تعبئة بطاقة المقابلة نفسها.
- [ ] "تمت" للمقابلة.
- [ ] تقديم عرض بتاريخ بدء وأجر basic 1200 USD وشروط:
  - [ ] ينتقل الطلب إلى "عرض".
  - [ ] يظهر "العرض بانتظار الاعتماد".
- [ ] بعد اعتماد العرض: "قَبِل". **(رفض)** "قَبِل" على عرض معلّق: لا يظهر الزر.
- [ ] بالحساب الذي لا يملك `hr.employees.create`: لا يظهر زر "تعيين"، وتظهر الملاحظة.
- [ ] "تعيين" بالحساب **أ**:
  - [ ] التاريخ من العرض.
  - [ ] يُفتح زر "فتح الملف".
  - [ ] ملف الموظف الجديد في الوحدة والمنصب ومع المدير.
  - [ ] أجره 1200 من تاريخ البدء.
  - [ ] مهام التهيئة ظاهرة.
- [ ] الطلب في "تعيين" على اللوحة. طلب التوظيف "مكتمل" لأن العدد 1.

## 6. إنهاء الطلبات
- [ ] رفض متقدّم بسبب: يظهر السبب على الطلب، ولا خطوات بعده.
- [ ] انسحاب متقدّم آخر.
- [ ] سحب عرض حيّ.

## 7. المتقدمون والخصوصية
- [ ] التوظيف والمواهب ← المتقدمون: البحث بالاسم والبريد والهاتف.
- [ ] تعديل بيانات متقدّم وملاحظاته.
- [ ] **محو** متقدّم:
  - [ ] يظهر تأكيد صريح.
  - [ ] يختفي هو وطلباته وسيرته.
  - [ ] موظف عُيّن منه يبقى ملفه.

## سؤال مفتوح
- مرشح هو موظف أصلاً: نافذة التعيين تحذّر بأن الانتقال الداخلي يُسجَّل نقلاً أو ترقية. هل يُمنع التعيين من هنا؟ القرار لمدير الموارد البشرية.
