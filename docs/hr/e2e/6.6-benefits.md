# 6.6 — المزايا

**الهدف:** ميزة تُسند إلى درجة أو وحدة أو موظف، وتُمنح شهرياً:
- البدل النقدي يُدفع مع الراتب.
- النقاط تصل إلى محفظة العضو.
- المنحة الفاشلة تُعاد أو تُلغى.
- تقرير كلفة الموظف يجمع الرواتب والمزايا.

## المتطلبات
- 6.5:
  - مكوّن "allowance": استحقاق، يُحتسب كـ"بدل ميزة"، **وفي كل قسيمة**.
  - دورة رواتب معتمدة.
- الحساب **د** (له محفظة) والحساب **هـ** (بلا محفظة)، في الدرجة نفسها.

## 1. المزايا (الرواتب والمزايا ← المزايا)
- [ ] بدل نقدي "بدل نقل" 40 USD شهرياً عبر مكوّن "allowance".
  - [ ] المكوّن الذي ليس في كل قسيمة لا يظهر في القائمة.
- [ ] نقاط المحفظة "نقاط المقهى" 200 نقطة شهرياً:
  - [ ] جيب "مقهى"، تنتهي بعد 30 يوماً.
  - [ ] كلفة 20 USD.
- [ ] استحقاق "تأمين صحي" بكلفة شهرية فقط.
- [ ] تعديل ميزة: الرمز والنوع والتكرار والعملة للعرض فقط.

## 2. الإسناد (صفحة الميزة)
- [ ] "نقاط المقهى" لدرجة **د** و**هـ** من أول الشهر.
- [ ] إسناد لـ **د** وحده بقيمة 300: الأخص يقرر. في ملف **د** ← المزايا تظهر 300 ومصدرها "إسناده الخاص".
- [ ] "حجب الميزة" عن موظف ثالث في الدرجة نفسها: لا تظهر في ملفه.
- [ ] **(رفض)** إسناد ثانٍ للهدف نفسه يتداخل في المدة: رسالة التداخل.
- [ ] إنهاء إسناد مبكراً. **(رفض)** إنهاؤه بعد تاريخ نهايته الحالي.

## 3. المنح (الرواتب والمزايا ← منح المزايا)
- [ ] "امنح الآن" للشهر: النتيجة "مُنح، سُلّم، فشل".
  - [ ] **د** سُلّمت نقاطه. تحقق من محفظته في تطبيق العضو أو صفحة العضو.
  - [ ] **هـ** فشلت منحته، وسبب الخادم ("لا يملك الموظف محفظة") يظهر عند الإشارة إلى الحالة.
- [ ] "امنح الآن" مرة ثانية للشهر نفسه: لا تتكرر المنح.
- [ ] "إعادة المحاولة" لمنحة **هـ**: تفشل مجدداً ويظهر السبب. بعد إنشاء محفظة له تنجح.
- [ ] إلغاء منحة معلّقة بعد تأكيد.
- [ ] البدل النقدي معلّق حتى دورة الرواتب:
  - [ ] احتسب دورة الشهر: يظهر سطر البدل في القسيمة.
  - [ ] بعد اعتماد الدورة تصبح المنحة "سُلّمت".

## 4. التقارير
- [ ] كلفة الموظف للشهر: الرواتب والمزايا والمجموع لكل عملة، والمجاميع في البطاقات.
- [ ] **د** ← مزاياي: مزاياه اليوم وقيمتها له وما مُنح له، بلا المنح الملغاة.

## الصلاحيات
- [ ] حساب بصلاحية `hr.benefits.manage` بلا `hr.payroll.view`:
  - [ ] قائمة مكوّنات الأجر في نموذج البدل فارغة، مع الملاحظة.
  - [ ] تقرير كلفة الموظف ممنوع.
