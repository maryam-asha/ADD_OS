# `src/add-os/` — كود ADD OS

كل ما نكتبه نحن يعيش هنا. كل ما عداه في `src/` هو قالب Pinx.

## القاعدة

> **كود القالب لا يُعدَّل.** أي تغيير سلوكي يمرّ عبر طبقة override داخل هذا المجلد.

الغاية: أن نبقى قادرين على ترقية Pinx مستقبلاً دون أن نضيع تغييراتنا في ملفاته.
القائمة الدقيقة لملفات vendor — ولنقاط التماس المعتمدة معها — في
[`_pinx-vendor/VENDOR-MANIFEST.md`](../../_pinx-vendor/VENDOR-MANIFEST.md).

## البنية

```
src/add-os/
├── modules/          وحدات ADD OS (فارغ — تُبنى وحدةً وحدة)
├── theme-overrides/  طبقات override للأنماط، ومنها RTL
├── lang/ar/          الترجمة العربية (اللغة الأساسية)
└── design-tokens/    مصدر التصميم الرسمي (بانتظار اعتماده)
```

## اتجاه الاعتماد

```
add-os  ──يستورد من──▶  pinx (vendor)        ✅ مسموح
pinx    ──يستورد من──▶  add-os               ⚠️ سطر واحد فقط، مسجَّل في المانيفست
```

الاستثناء الوحيد القائم اليوم هو re-export للعربية في
[`src/lang/locales/index.ts`](../lang/locales/index.ts)، لأن نظام i18n في القالب
يجمع اللغات من ذلك الملف حصراً.
